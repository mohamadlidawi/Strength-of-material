# Strength of Materials

A simple browser-based educational calculator for axial stress, strain, and deformation.

## Files
- `index.html` — the complete website. It includes the calculator, five example presets, result display, and a schematic visual representation.

## Run locally
Open `index.html` in a web browser. No installation or build step is required.

## Publish with GitHub and Vercel
1. Create a new GitHub repository named `strength-of-materials`.
2. Upload `index.html` and `README.md` to the repository.
3. In Vercel, choose **Add New → Project** and import the GitHub repository.
4. Deploy using the default settings. The site is a static HTML project, so no build command is needed.

Educational note: The visual deformation is magnified for visibility and is not drawn to scale.
